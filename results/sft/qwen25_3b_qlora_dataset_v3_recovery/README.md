# LoRA-адаптер PlantAdvisor v3

Адаптер обучен на датасете v3 для консультаций по комнатным растениям. Конфигурации, журналы обучения и оценки находятся рядом с этой карточкой. Выполненное обучение представлено в `notebooks/03_training_and_evaluation_v3.ipynb`.

- Базовая модель: `Qwen/Qwen2.5-3B-Instruct`, ревизия `aa8e72537993ba99e69dfaafa59ed015b17504d1`.
- Метод: QLoRA, NF4, `r=16`, `alpha=32`, dropout `0.10`, LR `3e-5`, 2 эпохи, 90 шагов.
- Данные: 360 train и 40 validation; хеши находятся в `training_config.json`.
- Адаптер: 504 тензора F32, 29 933 568 параметров, 119 801 528 байт в safetensors.
- Лучшая точка: шаг 90, `eval_loss=1.3437583446502686`.

В обычном Git сохранены конфигурация, окружение, логи и график. Веса и полный токенизатор входят в `plant_advisor_v3_reproduction_complete.zip`, публикуемый в GitHub Releases. Ссылка на него находится в корневом README.

После распаковки полного архива в корень копии репозитория адаптер находится в `adapter/`. Для загрузки нужно использовать ревизию базовой модели из `training_config.json`: поле `revision` внутри автоматически созданного `adapter_config.json` равно `null`.

FPR составил 100% против 73,3% baseline. На 29 общих оценках судьи корректность снизилась с 4,414 до 4,276, применимость — с 4,000 до 3,586. Улучшение формата не подтверждает улучшения содержания. Набор синтетический; полной независимой экспертной проверки советов не проводилось.
