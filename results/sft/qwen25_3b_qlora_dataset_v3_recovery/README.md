# LoRA-адаптер PlantAdvisor

Адаптер для русскоязычных консультаций по уходу за комнатными растениями и диагностике по описанию симптомов.

| Параметр | Значение |
|---|---|
| Базовая модель | `Qwen/Qwen2.5-3B-Instruct` |
| Ревизия | `aa8e72537993ba99e69dfaafa59ed015b17504d1` |
| Данные | 360 train / 40 validation |
| Метод | QLoRA, NF4, FP16 |
| LoRA | r=16, alpha=32, dropout=0,10 |
| Обучение | 2 эпохи, LR 3e-5, 90 шагов |
| Лучший eval_loss | 1,3437583446502686 на шаге 90 |
| Адаптер | 504 тензора F32, 29 933 568 параметров |

[Веса и токенизатор](https://github.com/Batyaoftheyear/plant-advisor/releases/tag/stage1-v3-reproduction) находятся в каталоге `results/sft/qwen25_3b_qlora_dataset_v3_recovery/adapter/` внутри ZIP. При загрузке базовой модели укажите ревизию из `training_config.json`: поле `revision` в `adapter_config.json` равно `null`. Токенизатор загружается из каталога адаптера.

[Выполненное обучение](../../../notebooks/03_training_and_evaluation.ipynb), конфигурация, окружение, журнал и кривая loss позволяют проследить параметры эксперимента.

FPR вырос с 73,3% до 100%. На 29 парных оценках судьи корректность снизилась с 4,414 до 4,276, применимость — с 4,000 до 3,586. Улучшение формата не сопровождалось улучшением содержательных оценок. Контрольный набор мал, данные синтетические, независимая экспертная проверка советов не проводилась.
