# QLoRA: первый эксперимент

Базовая модель: `Qwen/Qwen2.5-3B-Instruct`, ревизия `aa8e72537993ba99e69dfaafa59ed015b17504d1`. Данные: `data/train.jsonl` и `data/validation.jsonl`, 360/40 записей. Их SHA-256 совпадают с сохранённой конфигурацией обучения.

Параметры: 3 эпохи, LR `1e-4`, LoRA `r=16`, `alpha=32`, dropout `0.05`, NF4/FP16. Лучший checkpoint — шаг 45 с `eval_loss=1.8348503112792969`. В журнале до шага 135 validation loss растёт до 2.0100388526916504 и 2.021094560623169, что подтверждает описание в PDF.

`trainer_state.json` — оригинальный журнал checkpoint-135; `training_state_checkpoint45.json` — состояние лучшего checkpoint-45. `training_log.csv` получен из `log_history` без изменения чисел. `drive_artifacts_manifest.json` содержит происхождение и SHA-256 исходных файлов. Веса и токенизатор checkpoint-45 доступны через ссылку в корневом указателе артефактов.

Адаптер содержит 504 тензора F32 и 29 933 568 параметров. Проверены структура safetensors и конечность значений; отдельная проверочная загрузка на GPU при подготовке репозитория не выполнялась.
