# Пилот генерации диалогов по внешним источникам

В этом каталоге сохранены дополнительные результаты из Google Drive, `plant-advisor/results/dataset/`. Это отдельный пилот генерации с `Qwen/Qwen2.5-7B-Instruct`. Он не является текущим SFT-датасетом из 400 сценарных диалогов: ни один из восьми пилотных вопросов не совпадает с вопросами в опубликованном наборе после нормализации.

## Состав файлов

| Файл | Содержание |
|---|---|
| `generation_config.json` | Исходный набор данных и его ревизия, модель и ревизия весов, промпт, параметры генерации и seed |
| `generated_candidates.jsonl` | Все 8 ответов модели: исходный текст, разобранный JSON и число попыток |
| `pilot_examples.csv` | Те же 8 случаев с источниками, вопросами и ответами; поле ручных замечаний не заполнено |
| `selected_sources_index.csv` | Индекс 681 отобранного фрагмента: ID, сведения об источнике, URL, лицензия, категория, длина и SHA-256 текста |
| `pilot_audit.csv` | Проверка статусов, дословности evidence и совпадений с текущими SFT-вопросами |

Первые три файла скопированы с Drive без изменения байтов. Две последние таблицы сформированы при проверке скачанных результатов. Их происхождение и контрольные суммы указаны в [общем манифесте](../drive_artifacts_manifest.json).

## Входные материалы и параметры

В конфигурации указан `bmeyer2025/plantclinic-care-corpus`, ревизия `41adc30ed13857072654d790b2b0b2b524d517e7`. В скачанном `selected_sources.jsonl` — 681 уникальный `doc_id`: 446 из `stackexchange_gardening`, 228 из `wikipedia` и 7 из `zenodo`. В метаданных 674 записей обозначены `CC-BY-SA-4.0`, ещё 7 — `CC-BY-4.0`; исходные обозначения сохранены в индексе.

Индекс содержит сведения об отборе и хеши фрагментов, без полных текстов внешнего корпуса. Скачанный исходный JSONL сохранён в локальном кеше импорта. Все восемь ID пилота найдены в этом корпусе. Поле `source_ids_sha256` в конфигурации сохранено как есть; правило его расчёта не установлено, поэтому соответствие этого отпечатка всему списку из 681 ID не подтверждено.

Модель: `Qwen/Qwen2.5-7B-Instruct`, ревизия `a09a35458c702b33eeacc393d103063234e8bc28`. Настройки: до 512 новых токенов, `do_sample=false`, до 2600 символов источника, максимум две попытки, seed 42. В журнале каждого из восьми случаев фактически записана одна попытка.

## Результаты проверки

Модель вернула 6 записей со статусом `ok` и 2 со статусом `skip`. Среди шести ответов — по три категории `care` и `diagnosis`. Статус `ok` отражает ответ модели и не заменяет проверку содержания.

Разобранный JSON совпадает с исходным текстом ответа во всех восьми случаях; таблица `pilot_examples.csv` согласована с журналом и URL источников. У пяти из шести ответов поле `evidence` дословно найдено в соответствующем `passage_text`. Для `stackexchange_1463` дословного совпадения нет; в `pilot_audit.csv` это отмечено как `False`. Исходный ответ не исправлялся.

График `source_distribution.png` также скачан и просмотрен. Его количества и категории не соответствуют ни выбранным 681 фрагменту, ни текущему SFT-набору из 400 примеров. Поэтому он не включён как распределение этих данных. Его контрольная сумма сохранена в манифесте.

Основной анализ опубликованного набора находится в [ноутбуке подготовки SFT-данных](../../../notebooks/02_dataset.ipynb) и [описании датасета](../../../DATASET_CARD.md).
