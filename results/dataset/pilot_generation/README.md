# Пилот генерации диалогов по внешним источникам

Модель `Qwen/Qwen2.5-7B-Instruct` преобразует фрагменты внешнего корпуса в вопросы и ответы по комнатным растениям. Пилот включает восемь случаев. Они не входят в основной набор из 400 сценарных диалогов; совпадений нормализованных вопросов нет.

## Файлы

| Файл | Содержание |
|---|---|
| `generation_config.json` | Корпус, ревизии моделей и данных, промпт, параметры генерации и seed |
| `generated_candidates.jsonl` | Восемь исходных ответов, разобранный JSON и число попыток |
| `pilot_examples.csv` | Вопросы, ответы и источники; поля ручной оценки пусты |
| `selected_sources_index.csv` | Индекс 681 фрагмента: ID, URL, лицензия, категория, длина и SHA-256 текста |
| `pilot_audit.csv` | Статусы, дословность evidence и пересечения с обучающими вопросами |

[Манифест происхождения файлов](../drive_artifacts_manifest.json).

## Параметры

Корпус — `bmeyer2025/plantclinic-care-corpus`, ревизия `41adc30ed13857072654d790b2b0b2b524d517e7`. Отобрано 681 уникальное значение `doc_id`: 446 из `stackexchange_gardening`, 228 из `wikipedia`, 7 из `zenodo`. В метаданных 674 фрагментов указана лицензия `CC-BY-SA-4.0`, ещё 7 — `CC-BY-4.0`. Индекс содержит метаданные и хеши, без полных текстов корпуса.

Ревизия модели — `a09a35458c702b33eeacc393d103063234e8bc28`. Генерация: до 512 новых токенов, `do_sample=false`, до 2600 символов источника, максимум две попытки, seed 42. В каждом из восьми случаев зарегистрирована одна попытка.

## Результаты и ограничения

Получены шесть записей `ok` и две `skip`. Среди `ok` — по три задачи ухода и диагностики. Статус отражает решение генератора и не является экспертной проверкой.

У пяти из шести ответов поле `evidence` дословно встречается в `passage_text`. Для `stackexchange_1463` совпадения нет. Кроме того, ссылка на тематический источник не гарантирует, что рекомендации следуют из фрагмента. Эти ограничения послужили основанием отказаться от массового преобразования корпуса.

Формула `source_ids_sha256` в конфигурации не определена; соответствие этого отпечатка всему списку из 681 ID не подтверждено. Полная экспертная проверка рекомендаций не проводилась.
