# Соответствие требованиям этапа

[PDF-отчёт](report_rk1.pdf) сохранён без изменений. Проверка доступных материалов и расхождений с отчётом приведена в [REPORT_ARTIFACT_CHECK.md](REPORT_ARTIFACT_CHECK.md).

| Требование | Подтверждение |
|---|---|
| Постановка задачи | PDF, README и введение ноутбука 01: уход и диагностика комнатных растений по тексту |
| Тестовый запуск | Ноутбук 01; `results/baseline/qwen25_3b_512/quick_run.jsonl`, 2 случая |
| Автоматическая проверка и обоснование | FPR, положительные и отрицательные примеры в разделе 4 ноутбука 01 |
| Модель-судья | Рубрика, исходные ответы, объяснения, успешные оценки и журналы ошибок |
| Данные SFT | JSONL v2 и v3, 360 train / 40 validation, источники, метаданные и аудит |
| Дообучение | Выполненный ноутбук 03, логи и конфигурации v3; состояния Trainer и адаптер checkpoint-45 v2 |
| Оценка до/после | FPR по 30 вопросам, 29 парных оценок судьи, таблицы и примеры ошибок |
| Код на T4 в Colab | Ноутбуки, автоматическая загрузка входов с GitHub и инструкция README_DATASET.md |
| Веса | Адаптеры safetensors и токенизаторы через GitHub Releases, ссылки в ARTIFACTS.md |
| Метрики и графики | `results/baseline/`, `results/judge/`, `results/sft/`, `results/evaluation/` |
| Отчёт и ссылка для LMS | PDF в `docs/report_rk1.pdf`, репозиторий `github.com/Batyaoftheyear/plant-advisor` |

В текущих четырёх ноутбуках сохранены 112 выводов ячеек. Код, ответы, оценки и предупреждения выполненных ячеек не редактировались. Синтаксис и офлайн-проверки не равнозначны независимому повторению обучения на GPU.

Содержательное улучшение не заявляется: FPR вырос, оценки корректности и применимости снизились. Малый тест, синтетические данные и судья того же семейства ограничивают выводы. Точное соответствие весов числам 3,552 из PDF не подтверждено: у доступного полного комплекта v3 применимость равна 3,586. Это ограничение явно указано в README и сверке отчёта.
