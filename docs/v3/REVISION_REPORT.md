# Ревизия PlantAdvisor SFT: v2 → v3

## Изменения

| Показатель | v2 | v3 |
|---|---:|---:|
| Объём | 400 | 400 |
| Train / validation | 360 / 40 | 360 / 40 |
| Число растений | 25 | 25 |
| Семейства сценариев | 24 | **141** |
| Дословно одинаковые ответы | 0 | 0 |
| Пересечения семейств сценариев между train и validation | 0 | **0** |

В v3 **заменены содержательно все 400 обучающих пар**, а не просто перефразированы ответы v2. Новый банк включает условные вопросы с конкретным контекстом (изменение освещения, сушка субстрата, локальные симптомы, проверка вредителей) и 50 отдельных видоспецифичных случаев. У пустынного кактуса признаки описаны для стебля, а не для листьев.

Сведения об источниках переработаны: ссылки отмечены как *тематически релевантные*, не как отдельная доказанная цитата каждого ответа. Тест из 30 вопросов остался неизменным. Валидация по новым семействам сценариев делает задачу сложнее и помогает обнаружить запоминание шаблонов.

## Проверки

Автоматические результаты: `results/dataset/v3/v3_audit_summary.json`, `results/dataset/v3/v3_scenario_counts.csv`. Полностью совпадающих вопросов и ответов нет; точных пересечений с тестом нет. Формальная схема `user → assistant` соответствует третьему ноутбуку.

При интеграции данные v3 размещены в `data/v3/`, а новый вариант проверочного ноутбука — в `notebooks/02_dataset_v3.ipynb`. Данные, документация и выполненный второй ноутбук v2 восстановлены из предыдущего коммита без изменения содержания и выводов. Набор v1 сохраняется в `data/sft_metadata_raw.jsonl`.

## Неопределённость

Ботанические рекомендации не прошли независимую экспертную проверку всех 400 записей. Новая v3 не гарантирует улучшения метрик. Обучение и итоговая оценка требуют отдельного запуска на T4. Подбор гиперпараметров изменён одновременно с данными для уменьшения переобучения, поэтому чистый вклад изменения данных без отдельного абляционного эксперимента определить нельзя.
