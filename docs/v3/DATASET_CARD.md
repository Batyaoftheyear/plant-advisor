# PlantAdvisor SFT v3 — карточка датасета

**Назначение:** учебный SFT для Qwen2.5-3B-Instruct, русскоязычные консультации по комнатным растениям.

- Объём: **400** уникальных пар вопрос–ответ, из них train **360**, validation **40**.
- Типы задач: **200 care / 200 diagnosis**, поровну в обеих подвыборках.
- Охват: **25 растений**, **141 семейство сценариев** (132 train, 9 validation).
- Формат: JSONL с ключом `messages`, содержащим роли `user` и `assistant`.
- Диагностика строится как возможные причины → что проверить → что делать; не утверждает единственный установленный диагноз.

## Метод сборки

Синтетические примеры созданы из вручную составленного банка ситуаций, видоспецифичных случаев и профилей растений. Скрипт `scripts/build_sft_v3.py` воспроизводит сборку, используя справочник растений из `scripts/build_sft_dataset.py` (не его прежние обучающие пары). Зафиксирован `random.Random(20261119)`.

## Контроль качества

Проверяются: соответствие схемы, уникальность вопросов и ответов, отсутствие точного пересечения с 30 тестовыми вопросами, требуемые заголовки, распределение по группам и **полное отсутствие пересечений семейств сценариев между train и validation**. Все 400 примеров успешно прошли указанные автоматические проверки.

Фактическая точность каждого утверждения **не подтверждена экспертно**. Ссылки в `data/v3/sources.csv` и `data/v3/sft_provenance.csv` являются тематическими источниками, **не построчной атрибуцией**. Для содержательной оценки предусмотрен `results/dataset/v3/manual_review_v3.csv` (30 записей, незаполненные поля рецензии).

## Ограничения

Данные всё ещё синтетические и частично основаны на паттернах; рост числа сценариев сам по себе не доказывает повышение качества модели. Тестовые вопросы и baseline не изменялись. Улучшение оценивается отдельно на неизменном тесте, включая формат, проверку содержимого и LLM-as-judge.

## Размещение и запуск

Файлы v3 находятся в `data/v3/`, прежние `data/train.jsonl` и `data/validation.jsonl` сохраняют v2. Проверка выполняется `scripts/audit_sft_v3.py`. Запуск обучения и автоматическая загрузка из GitHub в Drive описаны в [README_DATASET.md](../../README_DATASET.md).
